## Para reemplazar por la foto real
Sube tu foto con **el mismo nombre de archivo** (ej. `mendocino.jpg`). Formato
JPG horizontal ~4:3, ancho ~800–1200 px, < 400 KB. La web recorta al centro
(`object-fit: cover`), así que centra el producto. Al reemplazar el archivo, la
foto nueva aparece sola.
